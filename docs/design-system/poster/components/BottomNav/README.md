# BottomNav

Bilah putih bersudut `radius-lg` dengan lima tujuan, diambil dari menu atas poster (Home, Post, Design…) dan dipindah ke bawah untuk jempol.

- Tab aktif: kotak kuning `sun` dengan teks `on-sun`, `aria-current="page"`. Tab lain `muted`.
- Label huruf sempit 13px di bawah ikon garis 22px (tebal 2).
- Mengambang `space-3` di atas tepi bawah ditambah `env(safe-area-inset-bottom)`.
