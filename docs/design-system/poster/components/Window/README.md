# Window

Kartu dialog dengan tag judul arang yang menempel menembus tepi atas, seperti tag "Kessoku Band" di atas foto pada poster. Dipakai untuk konfirmasi di halaman dan pemberitahuan.

- Tag judul berisi pertanyaan singkat ("Hapus belanja?"). Aksi yang menghapus data: `is-danger` (merah `bad`).
- Isi menyebut barang, nominal, dan tanggal nyata. Garis kuning pendek `kp-window-strip` (seperti bilah kuning di kartu profil poster) memisahkan isi dari tombol; hanya hiasan.
- Tombol di kanan: "Batal" dulu, lalu aksinya.
