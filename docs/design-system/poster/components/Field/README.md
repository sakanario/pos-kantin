# Field

Label, input, dan keterangan ditumpuk dengan jarak `space-1`.

- `kp-label` (gaya `small`, `muted`) memakai nama yang dikenali pengguna.
- `kp-input`: latar `card-raised` seperti kertas, tepi tipis `outline` (`stroke-thin`), sudut `radius-md`. Fokus: tepi `fg` dan `shadow-pop`.
- Nominal dan jumlah: `kp-num` + `inputmode="numeric"`. `kp-hint` untuk petunjuk, `kp-error` untuk galat yang bilang cara memperbaikinya.
