# Chip

Label-tag (`kp-tag`): bilah arang berteks putih dengan kotak putih di kanan, diambil dari daftar nama di poster. Dipakai untuk tap "Sendiri" dan pilihan dalam daftar; lencana (`kp-badge`) untuk status.

- Kotak kanan (`kp-tag-box`) berisi hitungan hari ini. Item yang baru ditekan atau dipilih: `aria-pressed="true"`, bilah jadi putih dan kotak jadi arang.
- Tag ditumpuk vertikal dengan jarak `space-2`, lebar mengikuti teks terpanjang, persis seperti daftar nama di poster.
- Lencana: `kp-badge` netral (jenis), `kp-badge-green` aktif, `kp-badge-warn` hampir habis, `kp-badge-bad` selisih kurang. Selalu berisi kata atau angka bertanda.
