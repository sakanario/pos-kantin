# Card

Panel putih `card` bersudut `radius-lg`, tanpa garis tepi, terangkat dari latar kuning oleh `shadow-pop-lg`.

- Pakai `kp-card` untuk tiap kelompok isi: ringkasan, daftar tap, form.
- Judul kartu `kp-card-title` (gaya `heading`, huruf sempit). Daftar pakai `kp-list` dengan pemisah `line`.
- Bidang di dalam kartu (isian, baris terpilih) pakai `card-raised`, bukan kartu bersarang.
- Jarak antar kartu `space-3`, antar bagian `space-6`.
