# Meter

Bar polos bersudut `radius-sm` untuk sisa kemasan bahan; jalur `line`, isian `accent` (arang; kuning di tema gelap).

- Lebar isian = persen sisa. Di bawah 30% tambah `is-low`: isian `warn`.
- Selalu tulis angkanya di bawah (`kp-hint`, "±15 cup lagi dari 25").
- Beri `role="progressbar"` dan `aria-valuenow`.
