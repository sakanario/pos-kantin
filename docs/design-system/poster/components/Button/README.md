# Button

Tombol persegi bersudut kecil dengan huruf sempit tebal dan bayangan lembut, seperti tombol "Add Friends" dan jempol di poster.

- `kp-btn kp-btn-primary` (arang `accent`; kuning di tema gelap): satu aksi utama per layar, mis. "Simpan belanja".
- `kp-btn kp-btn-sun` (kuning `sun`): aksi besar periode ("Tutup buku"), hanya di atas `card`.
- `kp-btn` (putih bertepi `outline`): batal, kembali.
- `kp-btn kp-btn-danger`: hapus dan koreksi, teks `bad`.
- `kp-btn-tap`: kotak 64×56 berisi "+1" di daftar tap racikan, seperti tombol jempol. Mode koreksi: `kp-btn-danger` dengan "−1".

Pengguna memberi: label berupa kata kerja dan `disabled` saat menyimpan. Tinggi minimal 46px.
