# Stat

Dua bentuk angka. `kp-hero`: satu angka besar langsung di atas `bg` dengan keterangan kecil di bawahnya, seperti jam "12:00" dan tanggal di poster. `kp-stat`: label putih kecil yang menempel di atas bilah arang berisi angka, seperti pasangan "Judul" dan "Bocchi The Rock!".

- Hero hanya satu per layar, biasanya "Uang bersih". Gaya `display`.
- `kp-stat-label` menamai angkanya dengan kata pengguna; `kp-stat-value` gaya `number`.
- Perubahan: `kp-stat-delta up` (`good`) atau `down` (`bad`) dengan tanda + atau − dan kata. Di atas `bg` kuning beri latar `card` supaya kontras cukup.
- Format rupiah "Rp 412.000".
