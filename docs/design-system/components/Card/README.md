# Card

Panel krem `card` bertepi `stroke` warna `outline`, sudut `radius-lg`, bayangan `shadow-pop-lg`.

- Pakai `kp-card` untuk tiap kelompok isi di halaman: ringkasan, daftar tap, form.
- Judul kartu `kp-card-title` (gaya `heading`). Daftar di dalam kartu pakai `kp-list`; pemisah barisnya `line` yang tipis, bukan `outline`.
- Jangan menumpuk kartu di dalam kartu. Untuk sorotan di dalam kartu pakai latar `accent-soft` atau `card-raised` tanpa tepi tebal.
- Jarak antar kartu `space-3`, antar bagian `space-6`.
