# Button

Tombol tebal bertepi `outline` dengan bayangan `shadow-pop` yang hilang saat ditekan, seperti tombol fisik.

- `kp-btn kp-btn-primary` (biru `accent`): satu aksi utama per layar, mis. "Simpan belanja".
- `kp-btn kp-btn-sun` (kuning `sun`): aksi besar periode ("Tutup buku"). Hanya di atas `card`, bukan langsung di atas `bg` kuning.
- `kp-btn` (polos): batal, kembali, aksi pelengkap.
- `kp-btn kp-btn-danger`: hapus dan koreksi; teks merah, isian tetap terang.
- `kp-btn-tap`: tombol +1 berbentuk pil 96×56 di daftar tap racikan. Saat mode koreksi pakai `kp-btn-danger` dan label "−1".

Pengguna memberi: label berupa kata kerja ("Simpan", "Hapus") dan atribut `disabled` saat menyimpan. Tinggi minimal 48px supaya enak ditekan jempol.
