# Window

Dialog konfirmasi: kartu kaca dengan bulatan "cangkir" espresso yang mencuat di tepi atas, seperti foto kopi yang keluar dari kartu menu di referensi.

- `kp-window` + `kp-window-cup` (ikon garis di dalam bulatan `accent`, dikelilingi cincin `card`). Untuk hapus/koreksi: `kp-window-cup is-danger` (merah `bad`).
- Judul `kp-window-title` berupa pertanyaan pendek ("Hapus belanja?"), lalu kalimat yang menyebut barang, nominal dan tanggal.
- Aksi rata kanan: tombol polos "Batal" lalu aksi (`kp-btn-danger` atau `kp-btn-primary`).
