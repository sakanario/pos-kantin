# BottomNav

Bilah navigasi pil espresso yang melayang di bawah layar; tab aktif berupa pil krem `card` dengan teks `fg`, seperti bilah di mockup HP referensi.

- Lima tab tetap: Beranda, Catat, Tutup Buku, Laporan, Lainnya. Ikon garis 22px tebal 2 di atas label.
- Tab tidak aktif: `accent-fg` sedikit pudar (tetap ≥ 4.5:1 di atas `accent`).
- Di tema gelap bilah menjadi krem latte dan tab aktif espresso, jadi tetap paling kontras dengan latar.
