# Button

Tombol pil berwarna espresso dengan bayangan gelap lembut di bawahnya, seperti "View Menu" dan "Contact Now" di referensi.

- `kp-btn kp-btn-primary` (espresso `accent`; krem latte di tema gelap): satu aksi utama per layar, mis. "Simpan belanja".
- `kp-btn kp-btn-caramel` (karamel `accent-2`): aksi kedua yang tetap berwarna, mis. "Lihat detail" atau "Learn More" di referensi.
- `kp-btn kp-btn-sun` (karamel muda `sun`): aksi besar periode ("Tutup buku").
- `kp-btn` (krem bertepi `outline`): batal, kembali. `kp-btn-danger`: hapus dan koreksi, teks `bad`.
- `kp-btn-tap`: pil 96×56 berisi "+1" di daftar tap racikan. Mode koreksi: `kp-btn-danger` dengan "−1".

Pengguna memberi: label berupa kata kerja dan `disabled` saat menyimpan. Tinggi minimal 46px.
