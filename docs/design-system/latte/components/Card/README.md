# Card

Panel krem seperti kaca buram: 90% tembus pandang dengan blur latar, kilau putih tipis di tepi atas, sudut `radius-lg` 24px, tanpa garis tepi, melayang oleh `shadow-pop-lg`.

- Pakai `kp-card` untuk tiap kelompok isi: ringkasan, daftar tap, form. Padding `space-5`.
- Judul kartu `kp-card-title` (gaya `heading`, Rubik). Daftar pakai `kp-list` dengan pemisah `line`.
- Bidang di dalam kartu (isian, baris terpilih) pakai `card-raised`, bukan kartu bersarang.
- Blur hanya untuk kartu dan dialog; chip, tombol dan navigasi tetap padat supaya teksnya tajam.
