# Meter

Bar sisa kemasan berupa 10 butir pil di alur `line`, diwarnai seperti lapisan kopi: espresso, lalu karamel, lalu crema.

- `kp-meter` berisi 10 `<i>`; butir yang terisi diberi `on`. Butir 1–4 `accent`, 5–7 `accent-2`, 8–10 `accent-3`.
- Hampir habis (≤ 20%): `kp-meter is-low`, semua butir `warn`, ditemani lencana "Hampir habis".
- Selalu ada teks di bawahnya ("±15 cup lagi dari 25"); warna saja tidak cukup.
