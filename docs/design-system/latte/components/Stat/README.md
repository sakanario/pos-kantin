# Stat

Angka penting ditulis besar di atas latar (`kp-hero`), dan angka ringkasan di kartu kecil dengan label harga pil yang menggantung di tepi bawah (`kp-stat` + `kp-price`), seperti harga "$2.50" di kartu menu referensi.

- `kp-hero`: satu per layar, angka `display` dengan keterangan `muted` di bawahnya.
- `kp-stat`: label `muted`, angka `number`, lalu `kp-price` berisi perbandingan atau nominal. `kp-price is-sun` untuk sorotan positif.
- Naik/turun selalu bertanda + atau − dan kata ("−Rp 6.000 kurang").
