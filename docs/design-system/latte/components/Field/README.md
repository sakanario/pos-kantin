# Field

Isian krem terang bersudut `radius-md` dengan tepi tipis `outline`; saat fokus tepinya karamel dan muncul cincin karamel tipis.

- `kp-field` membungkus `kp-label`, `kp-input`, dan `kp-hint` atau `kp-error`.
- Isian 16px supaya HP tidak memperbesar layar. Angka rupiah pakai `kp-num` dan `inputmode="numeric"`.
- Pesan galat menyebut apa yang harus diisi ("Isi sisa dulu, boleh 0.").
