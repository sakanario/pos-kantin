# Chip

Chip pil krem dengan label harga espresso di kanan, dan ubin ikon krem seperti deretan ikon kopi di referensi. Dipakai untuk tap "Sendiri", pilihan cepat, dan status.

- `kp-chip`: nama menu, hitungan hari ini (`kp-chip-count`, warna `muted`), lalu `kp-chip-badge` espresso berisi "+1". Mode koreksi: badge `kp-badge-bad` berisi "−1".
- `kp-icon`: ubin 52px bersudut `radius-md` berisi ikon garis; `aria-pressed="true"` membuatnya espresso.
- Lencana `kp-badge`: netral (jenis), `kp-badge-caramel` aktif, `kp-badge-warn` hampir habis, `kp-badge-bad` selisih kurang. Selalu berisi kata atau angka bertanda.
