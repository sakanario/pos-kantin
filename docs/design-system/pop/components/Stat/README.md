# Stat

Label kecil huruf besar, angka besar, lalu perubahan bertanda.

- `kp-stat-label` (gaya `caption`) menamai angkanya dengan kata pengguna: "Uang bersih", "Untung jualan", "Selisih".
- `kp-stat-value` (gaya `number`, Montserrat 800, tabular). Satu angka per layar boleh `is-hero` (gaya `display`).
- `kp-stat-delta up` (`good`) atau `down` (`bad`), selalu dengan tanda + atau − dan kata, bukan warna saja.
- Format rupiah: "Rp 412.000" (titik ribuan, tanpa desimal).
