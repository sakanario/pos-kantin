# Field

Label, input dan keterangan, ditumpuk dengan jarak `space-1`.

- `kp-label` (gaya `small`, warna `muted`) di atas, ditulis dengan nama yang dikenali pengguna ("Saldo Kantong Kantin sekarang").
- `kp-input` tinggi 48px, latar `card-raised`, tepi `outline`. Saat fokus tepinya `accent` dan muncul `shadow-pop`.
- Nominal rupiah dan jumlah: tambah `kp-num` dan `inputmode="numeric"`.
- `kp-hint` untuk petunjuk, `kp-error` untuk galat yang bilang cara memperbaikinya.
