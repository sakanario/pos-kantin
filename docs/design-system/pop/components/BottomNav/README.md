# BottomNav

Bilah navigasi bawah berbentuk pil mengambang, lima tujuan: Beranda, Catat, Tutup Buku, Laporan, Lainnya.

- Tab aktif: isian `accent`, teks `accent-fg`, `aria-current="page"`. Tab lain `muted`.
- Ikon garis 22px, tebal 2.5px, ujung membulat, warna mengikuti teks. Menggantikan emoji yang sekarang dipakai.
- Letakkan `space-3` dari tepi bawah layar ditambah `env(safe-area-inset-bottom)`, lebar maksimal sama dengan isi halaman.
