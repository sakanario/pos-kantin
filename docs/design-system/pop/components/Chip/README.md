# Chip

Tombol pil kecil (`kp-chip`) untuk tap "Sendiri", dan lencana (`kp-badge`) untuk status.

- Chip: nama menu, hitungan hari ini (`kp-chip-count`), lalu lencana "+1". Mode koreksi: lencana jadi `kp-badge-bad` berisi "−1".
- `kp-badge` (biru lembut): jenis atau kategori. `kp-badge-sun`: kemasan aktif. `kp-badge-warn`: hampir habis. `kp-badge-bad`: selisih kurang, rugi.
- Lencana selalu berisi kata atau angka bertanda, jangan hanya warna.
